# Vídeo do Hero

Coloque o arquivo `hero.mp4` nesta pasta para ativar o vídeo no Hero.

## Especificações recomendadas

- **Formato:** MP4 (H.264)
- **Duração:** 10–20 segundos
- **Tamanho:** preferir menos de 5 MB
- **Comportamento:** autoplay mudo, loop, playsInline

Sem o arquivo, o site usa automaticamente o collage de imagens.
